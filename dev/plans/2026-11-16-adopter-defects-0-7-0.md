**In brief**: Fix the small faults adopters hit upgrading to Cairn 0.7.0, most of them on Windows, and prove the Windows ones on Windows.

## Build summary

After this plan an upgrade on Windows no longer shows dozens of review-only files with no explanation. The report says when a file differs only in line endings, treats a file equal to its recorded release as an update, fills the empty flag text, and names a slot whose upstream placeholder changed. `session-start` stops printing stray carriage-return escapes and finds a lowercase `handoff` commit. The link check stops reporting an absent optional file, loses a hidden character, and refuses Windows network and drive targets before touching the disk. Installed module documents pass the claims check outside Cairn's tree, two shipped texts are corrected, and the Windows commit hook, which could not read staged paths, gets a named failure reason, then a repair, and a real commit run on Windows shows it working.
